# Dinheiro e Economia

Bitcoin é uma peça de software, mas as perguntas que ele tenta responder (o que faz algo funcionar como dinheiro, por que os sistemas monetários falham, quem deve controlar a oferta de uma moeda) são questões econômicas com séculos de argumento prévio atrás deles. Esta seção cobre esse argumento seriamente, apresentando escolas concorrentes de pensamento em seus próprios termos, em vez de tratar qualquer um deles como verdade estabelecida.

## O que você precisa saber primeiro

Nada além [Origens](../origins/README.md), o que explica por que essa questão importa para a história Bitcoin em primeiro lugar. Esta seção não assume o trabalho prévio do curso de economia. Cada conceito é introduzido a partir de seu problema subjacente, não seu rótulo do livro didático.

## Uma nota sobre como ler esta seção

Nenhuma escola de pensamento econômico aqui coberta é apresentada como correta. Quando capítulos descrevem um desacordo (dinheiro duro versus flexibilidade monetária, regras fixas versus discrição) ambos os lados são originados de textos primários, e este livro não resolve o desacordo em nome do leitor. Afirmações sobre o que um economista específico acreditava sobre Bitcoin são rotulados como interpretação posterior, a menos que esse economista escreveu sobre Bitcoin diretamente (nenhum dos quatro economistas austríacos abrangidos aqui fez, todos os quatro morreram antes ou logo após o whitepaper de Bitcoin foi publicado, com a exceção parcial de Hayek, que morreu em 1992).
