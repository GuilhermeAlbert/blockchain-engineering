# Origens

As ideias de Bitcoin não apareceram totalmente formadas em 2008. Esta seção cobre os trinta anos de criptografia, empresas fracassadas, argumentos de lista de discussão, e propostas inacabadas que vieram antes dele, e depois cobre os dois primeiros anos do Bitcoin como um sistema em execução.

## O que você precisa saber primeiro

Nada além da familiaridade geral com como os computadores trocam dados através de uma rede. Esta seção vem deliberadamente antes [Criptografia](../cryptography/README.md) e [Sistemas distribuídos](../distributed-systems/README.md)O objetivo aqui é o contexto histórico e motivacional, não o mecanismo. Seções posteriores explicam o "como" por trás das ideias desta seção apenas nomes, como funções de hash, assinaturas digitais e consenso.
