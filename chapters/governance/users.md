# Users and Node Operators

Users give a network economic meaning by choosing which assets, applications, and rules they accept. Node operators make that choice concrete by running software that validates specific rules. The category is broad: an individual wallet and a major exchange are both users, but their coordination power differs.

## Validation and economic acceptance

A fully validating node rejects blocks outside its rules regardless of miner or validator support. That protects its operator from accepting invalid history. It does not force trading partners to recognize the same branch or asset.

Businesses influence deposits, withdrawals, ticker symbols, custody, pricing, and payment acceptance. Wallets and infrastructure providers influence which chain users can access. Stablecoin issuers and oracle systems may choose one fork, bringing application state and off-chain claims with them.

## Collective action

One node refusing an upgrade preserves its own rule set but may end up on a small or stalled branch. User-activated changes depend on enough economic actors credibly coordinating enforcement. Public commitments, release availability, deadlines, and fallback plans affect that credibility.

The phrase “users decide” hides aggregation. There is no universal registry of user preference, and coin ownership, node count, transaction volume, and business size measure different things. Governance arguments should state which users and what observable action support the claim.

## Delegation and defaults

Most users do not inspect consensus code. They rely on wallet teams, node packages, exchanges, custodians, and service providers. Defaults therefore carry governance influence. Open alternatives and exit reduce dependence, but switching costs, custody, liquidity, and application compatibility can make exit difficult.

Running a node narrows data and validation trust. It does not remove reliance on developers for updates, hardware vendors, network connectivity, or one's own ability to respond to security notices.
